Core Library Documentation
====================================

The ``Cipher::core`` library: headers in `include/cipher/math <../../../../include/cipher/math>`_, `include/cipher/ring <../../../../include/cipher/ring>`_ and `include/cipher/util <../../../../include/cipher/util>`_; implementation in `source/ <../../../../source>`_ (``math/``, ``ring/``, ``util/``).

File Listings
-----------------------

`Cipher Core Top-Level Include (core.h) <../../../../include/cipher/core.h>`_

- Top-level ``#include "cipher/core.h"`` for access to all core capabilities

`Unit Test Definitions (test_defs.h) <../../../../tests/core/test_defs.h>`_

- Defines various macros for unit testing

`Version (version.h) <../../../../include/cipher/version.h>`_

- Get the current Cipher version, generated from the ``CMake`` project version
