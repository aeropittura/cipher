# Cipher Governance

Cipher is a small project maintained by its maintainers at <https://github.com/aeropittura/cipher>.

## Maintainers

The maintainers have write access to the repository. They review and merge pull requests, triage issues, decide on
releases, and enforce the [code of conduct](Code-of-conduct.md). New maintainers are invited by the existing ones.

## Decision making

Technical decisions are made in the open, in GitHub issues and pull requests. Anyone may propose a change by opening an
issue or a pull request (see [Contributing.md](Contributing.md)). The maintainers seek consensus in the discussion;
where none is reached, they decide.

Changes reach `main` only through pull requests that pass the CI and lint workflows and have been approved by a
maintainer.

## Releases

Releases are tagged on `main`. Changes that alter the public API or the serialization format are called out in the
release notes.

## Upstream

Cipher is derived from [OpenFHE](https://github.com/openfheorg/openfhe-development). The governance of the upstream
OpenFHE project (its teams, committees and processes) is documented by the OpenFHE project and does not apply to Cipher.
